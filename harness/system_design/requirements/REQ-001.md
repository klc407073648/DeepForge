# 需求：工作流状态人性化输出

## 1. 背景

闭环开发系统的 orchestrator CLI 当前 `status` 命令输出原始 JSON，不便于人工快速了解进度。需要增加人性化摘要输出，显示当前阶段、下一步建议、审批状态。

## 2. 用户故事

| ID | 角色 | 目标 | 价值 |
|----|------|------|------|
| US-1 | 开发者 | 一行命令看到 REQ 进度摘要 | 减少认知负担 |
| US-2 | 审核者 | 看到 plan/diagram 是否已批准 | 明确卡点 |

## 3. 验收标准

```yaml
acceptance_criteria:
  - id: AC-1
    given: 有效的 workflow state 字典
    when: 调用 format_status_summary(state)
    then: 返回含 req_id、stage、next_step 的多行字符串
  - id: AC-2
    given: state 含 approvals.plan
    when: 调用 format_status_summary(state)
    then: 输出中包含 plan 已批准标记
  - id: AC-3
    given: state 含 approvals 为空
    when: 调用 format_status_summary(state)
    then: 输出中显示 pending approvals 提示
```

## 4. 范围

### 做

- `src/workflow/status_formatter.py` 格式化函数
- `workflow.py status --human` 选项
- 单元测试

### 不做

- Web UI
- 多 REQ 批量汇总视图

## 5. 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 纯函数，无 I/O |
| 安全 | 不输出敏感信息 |

## 6. 依赖与约束

- 依赖现有 `scripts/workflow/workflow.py` 状态机定义
- 遵循 AGENTS.md 测试规范

## 7. 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| NEXT_SKILL 与 formatter 不同步 | 误导用户 | 从 workflow 模块导入映射 |
