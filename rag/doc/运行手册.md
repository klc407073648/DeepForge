# 运行手册

下面是该 RAG 项目在本地和 Docker 下的运行方式（含 React 前端）。

## 1. 准备后端环境

在 `rag` 目录下：

```powershell
cd d:\code\klc\test\DeepForge\rag
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 2. 配置 API 密钥

复制环境变量模板并编辑：

```powershell
copy .env.example .env
```

在 `.env` 里至少填写：

- `OPENAI_API_KEY`：你的 API Key
- `OPENAI_BASE_URL`：例如 `https://api.openai.com/v1` 或兼容网关地址

其余项可用 `.env.example` 中的默认值。也可在前端「API Key 管理」页写入运行时配置（保存到 `data/runtime_config.json`）。

## 3. 启动后端

```powershell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

浏览器可访问：

- 接口文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/health

## 4. 启动前端

另开终端：

```powershell
cd d:\code\klc\test\DeepForge\rag\frontend
npm install
npm run dev
```

浏览器打开：http://127.0.0.1:5173

前端通过 Vite 代理将 `/api/*` 转发到 `http://127.0.0.1:8000`。

### 前端页面

| 路由 | 功能 |
|------|------|
| `/knowledge` | 知识库：文档列表、上传/删除、切片设置 |
| `/chat` | 智能问答：选择模型与知识库、聊天、引用来源 |
| `/settings/keys` | API Key 管理：查看/编辑运行时配置 |

## 5. 调用流程（API）

1. `GET /health` — 确认 `ready: true`
2. `POST /ingest` 或 `/ingest/batch` — 上传文档建索引
3. `GET /documents` — 查看已索引文档
4. `POST /query` — `{"question": "你的问题", "model": "可选", "collection": "可选"}`

向量数据写在 `data/chroma/`；运行时配置写在 `data/runtime_config.json`（已在 `.gitignore` 中忽略）。

## 6. 用 Docker 运行（可选）

```powershell
docker build -t rag-service .
docker run --rm -p 8000:8000 -e OPENAI_API_KEY=你的密钥 -e OPENAI_BASE_URL=https://api.openai.com/v1 -v rag-chroma:/data/chroma rag-service
```

容器内持久化目录为 `/data/chroma`，需用卷挂载才能保留索引。

若 pip install 或启动报错，把完整终端输出贴出来即可排查。
